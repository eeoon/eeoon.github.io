2026

  1. ICROS
    다중 로봇 시스템의 학습 기반 이상 탐지를 위한 프레임워크 개발 (A Learning-based Anomaly Detection Framework for Multi-Robot Systems)
    Youngeon Kim, Yohan Jung, Dong Yeop Kim, and Keunhwan Kim
    In 제어로봇시스템학회 학술대회 (ICROS 2026), Jul 2026
    제1저자 Abs Bib

    제1저자

    Open-RMF 기반 10대 모바일 로봇 시뮬레이션에서 위치 오차·속도·배터리·임무 진행률을 시계열 feature로 정의하고, Transformer 기반 자기지도학습 모델(RESTAD)을 적용해 라벨 없이 다중 로봇 간 시공간 상관관계를 학습하여 이상을 탐지하는 프레임워크. Region-level 지표(Aff-F1 0.94)에서 LSTM·일반 Transformer를 능가했다. ICCAS 2025 룰 기반 이상탐지의 학습 기반 후속 연구.

2025

  1. ICCAS
    Anomaly Detection and Visualization Framework for Multi-Robot Systems Using RMF
    Youngeon Kim, Yohan Jung, Dong Yeop Kim, and Keunhwan Kim
    In 2025 25th International Conference on Control, Automation and Systems (ICCAS), Nov 2025
    제1저자 Abs Bib

    제1저자

    Defines four anomaly types in a multi-robot system (battery depletion, unexpected obstacle, trajectory conflict, collision risk within 0.2 m), detects them in a module decoupled from RMF task allocation, and visualizes them in real time on a WebSocket/ROS-bridge web dashboard. Validated in a Gazebo simulation with 30 mobile robots.

  2. ICCAS
    Design and Implementation of an OTA Update Framework for Software-Defined Robots using ROS 2 and Docker
    Dong Yeop Kim, Youngeon Kim, Eunsu Kim, Keunhwan Kim, Euntai Kim, and Deok Gyoon Chung
    In 2025 25th International Conference on Control, Automation and Systems (ICCAS), Nov 2025
    Abs Bib

    Proposes an over-the-air (OTA) update framework that realizes the Software-Defined Robot (SDR) paradigm with ROS 2 and Docker. A dual public-cloud / on-premise OTA server architecture with State and Usage Loggers is designed, and container-level modular deployment on the robot PC is validated with initial-install and update shell scripts as a proof of concept.

2024

  1. ICCAS
    Traversability Assessment and Path Planning Using Obstacle Recognition Information for Multi-Robot System
    YoungEon Kim, Dong Yeop Kim, and Keunhwan Kim
    In 2024 24th International Conference on Control, Automation and Systems (ICCAS), Oct 2024
    제1저자 Abs Bib

    제1저자

    Each robot detects dynamic obstacles (people) with an RGB-D camera and YOLOv8 and shares them with the RMF server. When the number of obstacles adjacent to a graph edge exceeds a predefined threshold, the edge is deactivated and affected robots proactively re-plan. Experiments with four robots show reduced collision risk and path cost compared with a non-cooperative system.

  2. ICROS
    상호 협력적 경로 계획을 위한 다중 로봇 시스템의 장애물 인식 정보 교차 활용 방법 (Method for Cross-Utilization of Obstacle Recognition Information in a Multi-Robot System for Collaborative Path Planning)
    Youngeon Kim, Keunhwan Kim, and Dong Yeop Kim
    In 제어로봇시스템학회 학술대회 (ICROS 2024), Jul 2024
    제1저자 Abs Bib

    제1저자

    다중 모바일 로봇이 각자의 2D LiDAR와 RGB-D 카메라(YOLOv8)로 탐지한 장애물 정보를 전역 맵 프레임으로 변환·공유하여, 다른 로봇도 해당 장애물 위치를 활용해 협력적 경로 계획을 수행하는 방법. Open-RMF 관제에서 장애물 기반으로 활성/비활성 경로를 구분해 로봇이 주행 가능한 경로만 따르도록 제어한다. Gazebo 2대 로봇 검증.

  3. KROC
    Open-RMF를 활용한 다중 이동로봇의 협력적 자율주행 시스템 (Cooperative Autonomous Driving System for Multi-Mobile Robots Using Open-RMF)
    Youngeon Kim, Keunhwan Kim, and Dong Yeop Kim
    In 제19회 한국로봇종합학술대회 (KROC 2024), Feb 2024
    제1저자 Abs Bib

    제1저자

    Open-RMF 미들웨어와 ROS Navigation을 통합한 서버-클라이언트 구조의 관제 시스템으로, 다중 이동로봇이 서버에서 작업을 할당받고 RMF Traffic Negotiation으로 충돌 없이 협력 주행하도록 구성하고 실로봇 실험으로 실현 가능성을 검증했다.
