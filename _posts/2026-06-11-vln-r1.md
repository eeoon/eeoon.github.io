## 한 줄 요약

VLN-R1은 별도의 지도·깊이센서·웨이포인트 예측기 없이, 1인칭 비디오만을 대형 비전-언어모델(Qwen2-VL)에 넣어 연속 환경(VLN-CE)에서 FORWARD/TURN-LEFT/TURN-RIGHT/STOP 네 가지 저수준 행동을 직접 예측하게 한 end-to-end 프레임워크다. 전문가 시범으로 SFT를 한 뒤, DeepSeek-R1식 GRPO 강화 미세조정(RFT)에 시간감쇠보상(Time-Decayed Reward, TDR)을 결합해 후학습한다. 그 결과 RGB만으로 지도·오도메트리·깊이를 쓰는 task-specific 기법을 넘어섰고, 2B 모델이 RFT만으로 7B SFT 모델을 따라잡았다.

## 연구 계보와 동향

- **그래프 기반·이산 VLN.** R2R(Anderson et al., 2018)과 RxR(다국어, 밀집 grounding)에서 시작했다. 에이전트가 미리 정의된 노드 사이를 텔레포트하며 언어-시각을 정렬하는 방식으로, 개방세계 일반화에 약했다.
- **전환 1: 연속 환경 VLN-CE.** Krantz et al.(2020) "Beyond the Nav-Graph"가 이산 웨이포인트를 저수준 모터 제어(회전각·보폭)로 바꿔 시뮬레이터 내 자유 이동을 도입했다. 그러나 깊이맵·전역지도, 웨이포인트 예측기(Hong 2022, Krantz 2021), CLIP 기반 정렬 등 추가 모듈에 의존했다.
- **전환 2: LLM/LVLM을 플래너로.** NavGPT, MapGPT, InstructNav 등은 시각을 텍스트로 변환한 뒤 LLM이 경로를 계획하게 했다. 여전히 이산 그래프와 3인칭에 갇히고 오류가 누적된다. NaVid/Uni-NaVid(RSS 2024/2025)가 비디오 기반 VLM으로 발전했으나 모듈형 시각 파이프라인에 의존한다.
- **전환 3: RFT의 VLN 도입(이 논문).** DeepSeek-R1/R1-Zero의 "RL만으로 추론 능력 향상" 발견과 GRPO(DeepSeekMath)를 VLN에 처음 이식했다. 검증가능보상(RLVR) 패러다임을 연속 내비게이션 의사결정에 적용한 첫 사례라 주장한다.
- **이후.** ETP-R1("Evolving Topological Planning with RFT for VLN-CE") 등 RFT 기반 VLN 계열이 파생되는 중이다.

## 문제와 동기

1. 기존 LLM 기반 VLN은 이산 토폴로지 그래프에 묶여 연속·미관측 환경으로 일반화되지 않는다.
2. 연속 환경(VLN-CE) 기법들은 깊이·지도·CLIP 같은 추가 센서와 모듈을 요구해 사람-에이전트 상호작용에서 확장성과 일반성이 떨어진다.
3. SFT만으로는 전체 텍스트 출력은 맞춰도 행동 단위(action-level)의 정밀 제어가 안 되며, 특히 다단계 미래 행동의 시간 의존성을 잡지 못한다.

따라서 "RGB 1인칭 비디오만으로 LVLM이 직접 행동을 내는 end-to-end 에이전트"를 만들고, 행동 수준 보상으로 후학습하자는 것이 출발점이다.

## 핵심 아이디어와 방법

### 데이터 엔진 VLN-Ego

Habitat 시뮬레이터(Matterport3D 90 scene: train 61 / val-seen 11 / val-unseen 18) 위에서 R2R·RxR 궤적을 따라 "1인칭 비디오 + 다음 6개 행동(ground truth)" 쌍을 자동 주석한다. 각 샘플은 세 부분으로 구성된다. (1) Instruction: 시스템 메시지 + 자연어 지시, (2) Vision: 과거 프레임 `<History Memory>` + `<Current Observation>`, (3) Action: 4지선다 옵션 A/B/C/D = FORWARD 25cm / TURN-LEFT 30° / TURN-RIGHT 30° / STOP. R2R 630K + RxR 1.2M으로 약 1.8M SFT 샘플을 얻었다.

### Long-Short Memory Sampling

"최근 프레임은 촘촘히, 먼 과거는 듬성듬성" 보는 프레임 선택 전략이다. 균일 샘플링은 최근성을 무시하고, 지수감쇠는 장기 맥락을 잃는다. 그래서 단기 메모리는 작은 간격 $$\delta_1$$로 촘촘히, 장기 메모리는 큰 간격 $$\delta_2 > \delta_1$$로 듬성하게 샘플한 뒤 합집합을 취해 최근 디테일과 장거리 맥락을 동시에 보존한다.

### 1단계: SFT

모델은 다음 $$n=6$$개 행동을 "A. Move forward 25cm, B. Turn left 30°, ..., D. Stop" 형태의 텍스트로 자기회귀 생성한다. 옵션 식별자(A/B/C/D)와 행동 서술문을 함께 교차엔트로피로 지도한다. 이산 기호(어떤 행동)와 자연어 서술(무슨 동작인지)을 동시에 생성하도록 학습해 합성적 추론을 유도한다.

### 2단계: RFT — GRPO + Time-Decayed Reward

**GRPO.** PPO의 critic도, DPO의 오프라인 선호 데이터도 필요 없다. 한 질문에 $$G$$개(여기서는 8개) 응답을 뽑아 그룹 내 보상을 평균·표준편차로 정규화해 상대 advantage $$A_i$$를 계산한다. 좋은 응답은 살짝 밀어주고 나쁜 응답은 조심히 누르며(클리핑), KL 페널티로 참조 모델에서의 과도한 이탈과 reward hacking을 막는다.

**TDR (핵심 기여).** 예측 행동열에서 옵션 $$\alpha_{t+k}$$만 뽑아 ground truth와 비교하되, 지수감쇠 $$\gamma^k$$를 곱한다.

$$
R_{\text{nav}} = \sum_{k=0}^{n-1} \gamma^k \cdot \mathbb{I}\left(\alpha_{t+k} = \alpha^{*}_{t+k}\right)
$$

"가까운 미래 행동을 맞히는 것이 먼 미래보다 훨씬 중요하다"는 직관이다. 단순 이진 매칭이나 ROUGE-L 같은 텍스트 유사도 보상은 시간 순서를 잡지 못한다는 것이 동기이며, SFT가 주지 못하는 위치 인식적(position-aware) 행동열 지도를 제공한다.

## 실험과 결과

**설정.** 백본은 Qwen2-VL-2B/7B(7B는 A800 8장 + DeepSpeed ZeRO-3). SFT는 1.8M 샘플 1 epoch 약 36시간(글로벌 배치 64, lr 5e-6 cosine). RFT는 각 데이터셋에서 10K씩 총 20K, GRPO 8 generations, lr 1e-6, $$\beta = 0.04$$, epoch당 약 12시간. 입력은 인스턴스당 16 이미지(최대 65,536px, 약 4.1K 토큰). 평가는 VLN-CE Val-Unseen(완전 미관측 18 scene)에서 SR/OS/SPL/NE/TL을 쓰며 입력은 RGB 비디오만이다.

**핵심 결과.**

| 설정 | SR (R2R Val-Unseen) |
|---|---|
| R2R-CMTP (지도+오도메트리+깊이) | 26.4 |
| VLN-SFT-2B | 21.2 |
| VLN-SFT-7B | 24.9 |
| VLN-R1-2B | 25.6 |
| VLN-R1-7B | 30.2 (OS 41.2 / SPL 21.8 / NE 7.0) |

1. **추가 센서 없이 SOTA.** VLN-R1-7B가 RGB만으로 지도·오도메트리·깊이를 쓰는 task-specific 기법(R2R-CMTP SR 26.4)을 넘어섰다.
2. **작은 모델이 RFT로 큰 모델을 따라잡음.** 2B+RFT(SR 25.6)가 7B-SFT(SR 24.9)를 넘겼다. DeepSeek-R1의 "RFT로 소형이 대형 수준에 도달" 관찰을 VLN에서 재현한 것이다.
3. **데이터 효율적 교차 도메인 적응.** R2R로만 SFT한 뒤 RxR을 단 10K 샘플로 RFT하면, 전체 RxR로 학습한 버전보다 성능이 좋다(VLN-R1-7B RxR SR 22.7 vs 풀데이터 22.3). RxR Val-Unseen에서 비교군 A2Nav(16.8), WS-MGMap(15.0) 등을 상회한다.

**Ablation (7B, R2R만 학습).**

- 행동 예측 길이: 단일 행동 SR 15.1 → 4행동 21.4 → 6행동 24.9 → 8행동 22.7. 6개가 최적이다.
- 프레임 선택: 균일 8 20.8 / 균일 16 22.0 / 지수감쇠 23.8 / Long-Short 24.9(단 OS는 지수감쇠 34.3이 더 높다).
- GRPO generation: k=2 24.7 → k=4 26.5 → k=6 28.4 → k=8 30.2. 8에서 수렴한다.
- 보상 함수: Hard 23.8 < Uniform 25.0 < Linear 28.3 < Exponential(TDR) 30.2.

**읽을 때 주의할 점.** R2R 표의 task-specific 비교군이 AG-CMTP/R2R-CMTP(2021)로 다소 오래됐고, NaVid/Uni-NaVid 같은 최신 비디오-VLM 베이스라인과의 동일 조건 비교가 본문 표에 없다. "RGB only로 SOTA"는 비교군 선택에 민감하다. 절대 성능도 Val-Unseen SR 30%대로 실사용과는 거리가 있다(논문도 인정). 행동공간이 TURN ±30°, FORWARD 고정거리의 이산 4행동이라 "연속 환경"이라지만 제어는 사실상 양자화되어 있다. 평가는 Habitat 실내 시뮬레이터에 한정되며 실로봇 검증은 없다. EQA 결과는 부록으로 미뤄져 본문 근거가 약하다.

## 결론과 의의

VLN-R1은 VLN을 "LVLM의 다운스트림 태스크"로 재정의하고, 검증가능보상(RLVR)+GRPO를 연속 내비게이션 의사결정에 처음 적용했다. 지도·깊이·웨이포인트 예측기 같은 무거운 모듈을 걷어내고 "비디오 → 행동"의 단순한 파이프라인으로도 경쟁력 있는 결과를 보였으며, 특히 소량 데이터 RFT로 교차 도메인 전이가 된다는 점은 데이터 수집이 비싼 임베디드 분야에서 실무적 시사점이 크다.

로봇 실무 관점에서 정리하면 다음과 같다.

- **어디에 쓸 수 있는가.** 새 건물·새 층으로 실내 다층 건물 모바일 로봇 자율주행을 확장할 때, 한 도메인에서 학습한 모델을 새 도메인 데이터 1만 개 수준의 RFT로 적응시키는 전략은 그대로 가져올 만하다. TDR 같은 시간 가중 보상 설계는 다단계 행동을 출력하는 어떤 정책에도 적용 가능하다.
- **소형 모델의 실용성.** 2B 모델이 RFT로 7B SFT를 따라잡는다는 결과는 온보드 배포 관점에서 의미가 있다. 다만 논문은 지연·실시간성 수치를 보고하지 않는다.
- **한계.** 시뮬레이터 실내 한정이라 sim-to-real 미검증, 이산·거친 행동공간으로 정밀 제어와 동적 장애물·사람 회피 미고려, TDR의 $$\gamma$$와 $$n=6$$ 선택이 더 긴 지평이나 실외에서도 유효한지 불명. GRPO 보상이 "GT 행동열 일치"이므로 expert 궤적 품질에 종속되며, 여러 유효 경로가 있는 상황의 보상 설계는 열린 문제다.
- **재현 난이도는 중상이다.** repo는 Apache-2.0이며 학습 데이터와 데이터 생성 파이프라인은 공개되었다. 그러나 확인 시점 기준 SFT 학습·테스트·RFT 섹션은 "진행중"으로 표기되어 핵심 학습·평가 코드의 완전 공개 여부가 불확실하고, VLN-R1 전용 학습 완료 체크포인트도 명확히 확인되지 않는다. 7B 학습은 A800×8에서 SFT 36시간 + RFT 12시간/epoch가 필요하다.
