## 한 줄 요약

π0.5는 이질적(heterogeneous) 데이터 소스의 공동학습(co-training)과 계층적 추론(고수준 서브태스크 텍스트 → 저수준 액션)을 결합해, 학습에 전혀 등장하지 않은 새로운 가정집에서 10~15분짜리 장기 다단계 모바일 조작(주방·침실 청소)을 end-to-end로 수행한 첫 VLA다. π0의 직계 후속이며, 무게중심을 "정교한 능력 시연"에서 "오픈월드 일반화"로 옮긴 논문이다.

## 연구 계보와 동향

계보는 RT-1/RT-2 → OpenVLA → π0(PaliGemma 백본 + flow matching 액션 전문가) → **π0.5** → π0-FAST → Knowledge Insulation(KI) → π0.6으로 이어진다. π0가 능력(dexterity)을 보였다면 π0.5는 일반화(generalization)를 겨냥했다. π0는 빨래 개기 같은 정교한 작업을 보였지만 학습 분포에 가까운 환경에서 평가됐고, π0.5는 "out-of-the-box로 새 집에서 동작"을 목표로 잡았다.

π0 대비 핵심 변화는 네 가지다.

1. **데이터 다양성.** 평가 대상인 모바일 조작 데이터는 약 400시간으로 전체의 2.4%에 불과하다. 나머지 97.6%는 다른 로봇·웹·고수준 라벨 등 간접 지식이다. "일반화는 스케일만으로는 부족하고 여러 추상화 층위의 지식 전이가 필요하다"는 명제를 정면으로 검증한다.
2. **계층적 추론.** 동일 모델이 고수준 서브태스크 텍스트("pick up the plate")를 먼저 예측하고, 그 텍스트를 조건으로 저수준 액션 청크를 생성한다. π0의 평면(flat) 정책에서 chain-of-thought식 2단계로 진화했다.
3. **하이브리드 액션 표현.** 사전학습은 FAST 이산 토큰(빠른 학습), 후처리학습은 flow matching 연속 액션 전문가(실시간 추론·정밀도)를 쓴다. 두 표현은 attention mask로 분리된다.
4. **언어 지도(Verbal Instruction) 모달리티.** 사람이 실시간 언어로 로봇을 단계별로 코칭한 "언어 시연"을 고수준 정책 학습에 사용한다.

동시대 경쟁작으로는 GR00T N1(NVIDIA), AgiBot World, RT-H 등이 있다. π0.5의 차별점은 "새 집에서 장기 작업"이라는 평가 난이도다. 관련 선행으로 SayCan은 LLM으로 고수준 단계를 고르고 별도 저수준 정책이 실행하는 2모델 구조인데, π0.5는 이를 한 모델로 통합했다. Embodied Chain-of-Thought는 고수준 추론을 저수준과 같은 빈도로 돌리지만, π0.5는 고수준을 저주파로 돌려 효율화한다.

## 문제와 동기

오픈월드 일반화는 physical intelligence의 최대 난제다. 로봇은 실험실을 벗어나 본 적 없는 다양한 상황을 다뤄야 비로소 유용해진다. 새 주방 청소를 예로 들면 일반화가 여러 층위에서 필요하다.

- 데이터에 충분히 표현되면 바로 일반화되는 행동(접시 집기)
- 기존 스킬을 새 방식·새 순서로 변형하는 것
- 장면 의미 이해(어느 서랍을 열지, 카운터 위 어떤 물건이 건조대인지)

단순 스케일링으로는 두 번째와 세 번째를 채우기 어렵다. 사람은 직접 경험뿐 아니라 남에게 들은 것, 책에서 읽은 것, 다른 과제의 통찰을 종합한다. 로봇 학습 시스템도 다양한 정보원에서 지식을 전이해야 한다는 것이 이 논문의 가설이다. 무엇보다 주방 청소 같은 장기·복잡 작업은 모든 그럴듯한 시나리오를 로봇 데이터로 brute-force 수집하는 것이 현실적으로 불가능하므로, 이질적 소스 co-training이 유일한 길이라는 주장이다.

## 핵심 아이디어와 방법

### 단일 모델, 두 가지 역할 (계층적 정책)

정책 분포를 다음과 같이 분해한다.

$$
\pi_\theta(a, \hat{\ell} \mid o, \ell) = \pi_\theta(\hat{\ell} \mid o, \ell) \cdot \pi_\theta(a \mid o, \hat{\ell})
$$

- **고수준:** 관찰 $$o$$와 전체 명령 $$\ell$$("clean the kitchen")로부터 서브태스크 텍스트 $$\hat{\ell}$$("pick up the plate")을 예측한다. 관련 bounding box도 먼저 예측한다.
- **저수준:** 관찰 $$o$$와 서브태스크 $$\hat{\ell}$$로부터 액션 청크 $$a$$를 생성한다. 액션은 원래 명령 $$\ell$$이 아니라 서브태스크 $$\hat{\ell}$$에만 의존한다는 점이 중요하다.

비유하자면 한 사람이 "머릿속으로 다음 할 일을 한 줄 적고"(고수준) 그 메모를 보고 손을 움직이는(저수준) 것이다. 같은 뇌, 두 모드다. 고수준은 저주파로, 저수준은 고주파로 실행된다.

### 하이브리드 이산 + 연속 액션

이산 토큰(FAST)은 학습이 빠르지만 추론 시 비싼 autoregressive 디코딩이 필요해 실시간 제어에 부적합하다. flow matching 연속 액션은 추론이 빠르지만 학습이 느리다. π0.5는 두 표현을 모두 학습하되 단계별로 역할을 나눈다.

| 단계 | 액션 표현 | 손실 가중치 | 스텝 |
|---|---|---|---|
| 사전학습 | FAST 이산 토큰(표준 VLM처럼 next-token) | $$\alpha = 0$$ | 280k |
| 후처리학습 | flow matching 액션 전문가(300M, 랜덤 초기화) 추가 | $$\alpha = 10$$ | 80k |

결합 손실은 텍스트 토큰(FAST 인코딩 액션 토큰 포함)의 cross-entropy에 flow matching 항을 더한 형태다. 노이즈 $$\omega \sim \mathcal{N}(0, I)$$에 대해 $$a^{\tau, \omega} = \tau a + (1 - \tau)\omega$$를 만들고, 모델이 벡터장 $$\omega - a$$를 예측하도록 학습한다.

$$
\mathcal{L} = \mathcal{L}_{\text{CE}}(\text{text, FAST tokens}) + \alpha \left\| (\omega - a) - f^a_\theta(a^{\tau,\omega}, o, \hat{\ell}) \right\|^2
$$

두 액션 표현은 attention mask로 서로 보지 못하게 분리해 정보 누수를 차단한다. 추론 시에는 텍스트 $$\hat{\ell}$$을 autoregressive로 디코딩한 뒤, 그 조건 하에 10 denoising step으로 연속 액션을 생성한다. 비유하면 시험 공부는 객관식으로 빠르게 개념을 암기하고, 실전은 서술형으로 정밀하게 답안을 쓰는 셈이다.

### 이질적 co-training 데이터

| 약어 | 소스 | 역할 |
|---|---|---|
| MM | Diverse Mobile Manipulator: 약 100개 가정, 약 400시간 | 평가와 가장 직접 관련 |
| ME | Multi-Environment 비모바일 로봇 | 가볍고 운반이 쉬워 더 다양한 집에서 수집(다른 embodiment) |
| CE | Cross-Embodiment 실험실 데이터 | 단·양팔, static/mobile, OXE 오픈소스 포함 |
| HL | High-Level 서브태스크 예측 | 로봇 데이터에 수동 서브태스크 라벨 + bounding box 주석 |
| WD | Multimodal Web Data | 캡셔닝(CapsFusion, COCO), VQA(Cambrian-7M, PixMo, VQAv2), 객체 위치화(실내 장면 추가 수집) |
| VI | Verbal Instruction(후처리학습만) | 전문가가 실시간 언어로 저수준 정책을 "텔레오퍼레이션"하며 좋은 고수준 출력을 시연 |

VI는 전체 고수준 모바일 예제의 약 11%에 불과하지만 결정적이다. 모든 액션 데이터는 목표 관절·엔드이펙터 포즈를 예측하도록 학습하고, 액션은 각 차원의 1%·99% quantile로 $$[-1, 1]$$에 정규화하며, 저차원 로봇은 가장 큰 액션 공간에 맞춰 zero-pad한다.

### 백본과 구조

- **백본:** PaliGemma VLM = SigLIP(400M) 비전 + Gemma(2B). width 2048, depth 18, MLP 16384, heads 18.
- **액션 전문가:** 300M(width 1024, MLP 4096). MoE와 유사하게 액션 토큰만 별도 가중치로 처리한다. action horizon은 50이다.
- **timestep 주입:** π0와 달리 $$\tau$$를 noisy action에 fuse하지 않고, 별도 MLP와 adaptive RMSNorm으로 각 층에 주입한다. flow timestep은 저구간을 강조하는 Beta 분포에서 샘플한다.
- **attention:** 이미지·프롬프트·proprioception은 양방향 prefix mask. FAST 토큰은 prefix와 이전 액션 토큰에 autoregressive로 attend. 액션 전문가 임베딩은 prefix와 자기들끼리만 attend하고 FAST 토큰은 보지 않는다. 즉 정보는 VLM → 액션 전문가로 단방향으로 흐른다. 이 설계가 후속 Knowledge Insulation과 π0.6의 전신이다.

## 실험과 결과

**로봇 시스템.** 모바일 매니퓰레이터 2종. 6 DoF 양팔 + 평행 그리퍼, 홀로노믹 휠 베이스(3 DoF), 토르소 리프트(1~2 DoF), 카메라 4대(전·후방 + 양 손목). 상태/액션은 18~19 DoF다. π0.5가 50Hz로 팔·그리퍼·리프트 목표 포즈와 베이스 속도를 직접 명령하며(action chunking), 단순 PD 추종기만 있고 궤적 계획·충돌 검출은 없다. 항법과 조작 모두 end-to-end다.

**평가 환경.** 모든 실험은 학습에 없던 새 환경에서만 수행했다. 정량 비교는 재현 가능한 mock 방, 최종 평가는 실제 집 3채다.

핵심 결과 세 가지는 다음과 같다.

**1. 새 집 일반화.** 학습에 전혀 없던 실제 가정 3채에서 주방·침실 청소(접시 싱크에 넣기, 서랍 정리, 빨래 바구니 등) 다단계 작업(2~5분, 일부 10~15분)을 일관되게 성공했다. end-to-end 학습 시스템이 새 집에서 이 수준의 장기·정교 작업을 한 첫 사례로 저자들은 주장한다.

**2. 간접 데이터가 본질이다.** ME/CE(다른 로봇) 중 하나라도 제거하면 성능이 크게 떨어지고, 둘 다 빼면 더 악화된다. 즉 cross-embodiment 전이가 핵심이다. WD(웹)를 제거하면 mock 4과제에서는 유의미한 차이가 없었지만, 미학습 카테고리(OOD) 객체에 대한 언어 추종이 크게 악화됐다. VI를 제거하면 고수준 정책이 급락했다.

**3. 환경 수 스케일링.** 학습 환경 수를 3·12·22·53·82·104로 늘리면 4과제 평균 성능이 단조 증가했다. 104개 환경 모델은 테스트 집 데이터가 0인데도 테스트 집을 직접 학습에 넣은 control 모델 성능에 근접했다. co-training 없이 모바일 데이터만 쓴 baseline은 훨씬 나빴다. 언어 추종률과 성공률도 환경 수와 함께 향상됐으며 in-distribution이 더 빨리 올랐다.

**상세.**
- **π0 대비.** 원본 π0와 개선판 π0-FAST+Flow(joint diffusion + FAST를 HL·WD 없이 액션 데이터만으로 학습) 모두를 π0.5가 유의하게 상회했다. π0를 300k step까지 더 학습시켜도 결과가 유지돼, FAST 토큰 학습이 순수 diffusion보다 compute 효율적이라는 FAST 논문의 결론을 재확인했다.
- **고수준 추론 ablation.** full π0.5가 최고이며 사람 oracle(human HL)보다도 높았다. 둘째는 놀랍게도 implicit HL(런타임 고수준 추론 없이, 학습에만 HL 데이터 포함)이었다. 명시적 추론 이득의 상당 부분이 단지 HL 데이터를 섞은 것에서 나온다는 뜻이다. no HL(데이터까지 제거)은 크게 하락했다. zero-shot GPT-4를 고수준 정책으로 쓰면 최악이었고, 이는 로봇 데이터로 VLM을 적응시키는 것이 중요함을 보여준다.
- **과제별 분해.** "Items in Drawer"는 웹 데이터 제거 시 급락(덜 본 객체의 일반화에 의미 지식이 중요)했고, "Laundry Basket"·"Dishes in Sink"는 고수준 정책 선택에 덜 민감했다(horizon이 짧거나 의미 추론이 덜 필요).
- 프로젝트 블로그는 환경 수가 충분할 때 in-distribution 약 83%, OOD 약 94% 수준의 언어 추종/성공 지표를 보고한다.

**주장 대 실제.** "새 집에서 장기·정교 조작을 한 첫 시연"은 정량 평가가 mock 방 위주이고 실제 집은 3채·10 trial 규모로 표본이 작지만, 새 환경 한정 평가라는 점에서 대체로 성립한다. "co-training이 일반화의 본질"은 ablation으로 각 소스의 기여를 분리 입증해 설득력이 높다. 다만 "왜 implicit HL이 그렇게 강한가"는 부분적 설명에 그치고, "104개 환경 ≈ control"은 mock 환경·4과제 한정이므로 과대 해석은 주의해야 한다.

## 결론과 의의

π0.5는 VLA 연구의 무게중심을 "능력 시연"에서 "오픈월드 일반화"로 옮긴 분기점이다. 로봇 데이터를 무작정 늘리기보다 이질적 지식 전이 레시피 설계가 일반화의 열쇠임을 실증했다. "동일 모델 계층 추론"과 "이산 사전학습 + 연속 후처리학습" 하이브리드는 이후 표준 패턴이 됐고, attention 분리 설계는 Knowledge Insulation(액션 전문가의 gradient가 VLM 백본으로 역전파되지 않게 차단해 사전학습 지식 보존)을 거쳐 π0.6으로 직접 이어진다.

로봇 실무 관점에서의 활용 가능성과 한계는 다음과 같다.

- **파인튜닝·추론은 접근 가능하다.** openpi(JAX/Flax + PyTorch)에 `pi05_base`(파인튜닝용), `pi05_libero`(LIBERO), `pi05_droid`(DROID, KI 적용) 체크포인트가 Apache-2.0으로 공개돼 있다. 추론 8GB 이상, LoRA 파인튜닝 22.5GB 이상(RTX 4090), 풀 파인튜닝 70GB 이상(A100/H100)이 필요하다. LIBERO/DROID 벤치 재현은 중 수준이다.
- **논문 결과의 재현은 사실상 불가능하다.** 새 집 일반화는 자체 모바일 매니퓰레이터 2종, 약 400시간의 가정 데이터, 100개 환경에 의존하며 모두 비공개다. 재현 난이도는 상이다.
- **실내 다층 건물 모바일 로봇 자율주행 관점의 시사점.** 항법과 조작을 모두 end-to-end로 처리하고 궤적 계획·충돌 검출이 없다는 점은 흥미롭지만, 컨텍스트·메모리가 빈약해 방 사이 이동이나 물건 위치 기억 같은 부분관찰 작업에 약하다는 한계가 명시돼 있다. 층간 이동이나 긴 경로가 필요한 시나리오에는 별도의 메모리·계획 모듈이 필요할 것이다.
- **여전히 실수한다.** 낯선 서랍 손잡이, 물리적으로 열기 힘든 캐비닛, 부분 관찰(팔이 닦아야 할 흘림을 가림), 고수준 추론의 산만함(서랍을 여닫기 반복) 등이 보고됐다. 단순 프롬프트만 처리하며, 복잡한 선호·지시에는 더 풍부한 주석이 필요하다.
- **열린 질문.** implicit HL이 명시적 추론에 근접하는 메커니즘, 여러 방에 걸친 더 긴 horizon으로의 확장, VI 외의 인간 지식 주입 방식은 미탐구다.
