## 한 줄 요약

PGTT는 보행 리듬(gait prior)을 오실레이터나 IK로 행동 공간에 강제하는 대신, 지형 적응형 Hermite 스플라인 발끝 궤적을 "보상에만" 넣는 인지형(perceptive) 사족보행 강화학습이다. 정책은 관절 공간에서 자유롭게 행동하면서도 리듬 구조의 이점을 얻는다. MuJoCo MJX와 소비자급 GPU 한 장으로 학습하고 Unitree Go2 실기에 LiDAR elevation map 인지로 이식했으며, 외란과 이산 장애물에서 베이스라인 대비 성공률을 7.5~9%p 높였다.

## 연구 계보와 동향

**Blind RL의 성공과 한계.** Lee 등(2020)은 고유수용감각만으로 험지 보행을 보였지만, 장애물을 "예측"하지 못해 뒷다리 지형과 이산 장애물에 취약했다.

**인지의 두 방식.** egocentric depth 카메라 end-to-end(Agarwal 2022)는 시야 한계, 노이즈, 시간 메모리 부담이 있고 특히 뒷다리 지형을 관측하지 못한다. 전역 elevation map + 멀티센서(Miki 2022)는 예지력이 늘지만 캘리브레이션과 전역 pose 추정에 의존해 취약하다. 절충으로 로봇 중심 로컬 하이트맵이 최근 수렴점이 되었다.

**Gait prior의 관례와 문제.** Wild(Miki 2022) 계열은 다리별 위상으로 발·관절 목표를 규정하고 IK + PD로 추종한다. 안정적이지만 행동 공간을 제약하고 정책을 로봇 형태(morphology)에 결박한다. CPG-RL도 같은 한계를 물려받는다. prior 없는 쪽은 MassLoco(Rudin 2022 + Margolis 보상)로, 자유롭지만 보상 항이 많고 수렴이 느리다.

**PGTT의 위치.** Shao 등(RA-L 2022)이 연 "위상을 목적함수에 넣는" 방향에 지형 적응(로컬 하이트맵 통계로 스윙 정점 조절)을 결합한 것이 계보상 위치다. 구조를 action이 아닌 reward에 넣어 "리듬의 이점 + 무제약 행동 공간 + 형태 무관"을 동시에 노린다. 학습 인프라도 Isaac Gym 일변도에서 MuJoCo MJX + BRAX + PPO로 옮겨 접근성 자체를 기여로 내세우며, MuJoCo Playground와 동시대 흐름이다. 인용 축적은 초기 단계다.

## 문제와 동기

인지형 보행 RL 컨트롤러는 (i) 오실레이터/IK gait prior로 행동 공간을 제약해 최적화를 편향시키고 로봇 형태 간 이식을 막거나, (ii) blind로 동작해 뒷다리 지형을 예측하지 못하고 관측 노이즈에 취약하다. "리듬 구조의 이점은 유지하되 행동 공간은 건드리지 않는" 방법이 필요하다. 구조를 어디에 넣을 것인가, action인가 reward인가가 이 논문의 질문이다.

## 핵심 아이디어와 방법

한 문장으로 요약하면, 다리별 위상과 로컬 하이트맵 통계로 정의되는 지형 적응형 cubic Hermite 스플라인 발높이 궤적을 정책이 "추종하면 보상받는" 항으로만 사용하고(IK 없음), 정책 자체는 관절 공간에서 직접 행동한다.

### 인지: 로봇 중심 하이트맵

N×M 등간격 격자를 로봇 몸 프레임에 앵커해 정책 입력으로 직접 쓴다. 전역 pose나 멀티센서 캘리브레이션이 필요 없고, 앞뒤 다리 모두의 국소 기하를 포착한다. 시뮬레이션은 ground truth, 실기는 LiDAR elevation mapping에서 온라인 추출한다.

### 위상 인코딩과 지형 적응 스플라인 (보상 전용)

다리별 위상 $$\phi_i \in [0, 2\pi)$$ 를 두고 $$[0, \pi)$$ 는 접지, $$[\pi, 2\pi)$$ 는 스윙으로 해석한다. 위상은 기본 주파수 $$f$$ 로 진행하고 관측에는 $$\cos\phi, \sin\phi$$ 로 들어간다.

스윙 궤적은 세 구간의 cubic Hermite 스플라인이다. 스탠스(공칭 발높이 $$d_b$$ 유지) → 스윙업($$d_b \to d_s + \delta H$$) → 스윙다운($$d_s + \delta H \to d_b$$). 여기서 핵심은 지형 적응 항이다.

$$
\delta H_i = H_{max,i}(h_t) - H_{min,i}(h_t)
$$

다리 주변 하이트맵의 최고·최저 높이 차이를 스윙 정점에 더하므로, 지형이 험할수록 발이 자동으로 더 높이 올라가 장애물 클리어런스를 보장한다. 스플라인 파라미터는 시간이 아니라 위상 좌표로 표현된다.

보상은 공통 항(속도 추종, 자세, 토크 등)에 PGTT 고유 항 두 개만 더한다.

| 항 | 정의 | 가중치 |
|---|---|---|
| foot phase | $$\sum_i \exp\big(-(p^{des}_{f,z,i} - p_{f,z,i})^2 / \sigma_f\big)$$, $$\sigma_f = 0.05$$ | 1.0 |
| foot contact | 스윙 위상 중 접지 페널티 $$\sum_i \mathbb{1}[\pi \le \phi_i < 2\pi] \cdot c_i$$ | -0.25 |

MassLoco가 필요로 하는 4개 추가 항(클리어런스, 슬립, 에어타임, 정지)보다 적다.

### 학습 구조

- **행동:** $$q_{des} = q_{stand} + k \cdot a$$, 12관절 목표각 직접 출력(IK 없음), 저수준 PD로 토크 변환.
- **관측:** $$o = [\omega, g, q, \dot{q}, \cos\phi, \sin\phi, h, f, a_{prev}, v_{cmd}]$$ — 몸통 각속도, 중력 벡터, 관절각·각속도, 위상, 하이트스캔, 기본 주파수, 직전 행동, 명령.
- **비대칭 actor-critic:** critic만 특권 정보(몸통 선속도)를 받는다. teacher-student 증류가 갖는 "교사 점유측도에 결박"되는 문제를 피하는 선택이다.
- **지형 생성:** Wave Function Collapse(WFC)로 계단 세그먼트, 코너, 평지 타일을 제약 충족 방식으로 배치한다. 5×5 타일, 로봇은 중앙 스폰.
- **커리큘럼 4레벨:** 단차 높이 [1,3] → [1,7] → [1,10] → [1,13] cm. 속도 추종 지표 $$m_v, m_\omega \ge 0.65$$ 달성 시 승급. 도메인 랜덤화는 관측 노이즈, 질량, 기본 자세, 모터 게인, 마찰.
- **스택:** MuJoCo MJX(GPU 물리) + BRAX + PPO, 물리 dt 5ms, 제어 50Hz. actor·critic 모두 MLP 512-256-128이다. 하이트맵 입력에는 메모리 기구가 불필요하다는 선행 근거를 따랐다. $$f \sim U[1,3]$$, 명령은 에피소드 중 1회 재샘플.

## 실험과 결과

**학습 환경:** i9-14900K + RTX 5070 한 장. 4레벨 완주 평균 wall-time은 PGTT 195분, Wild 198분, MassLoco 239분으로 "소비자 GPU 반나절"을 실증했다.

**베이스라인 설계:** MassLoco와 Wild를 보상 항만 교체하고 관측, 특권 상태, 네트워크, 지형, 공통 보상 가중치를 전부 동일하게 맞췄다. 순수하게 "보상 구조"의 효과를 분리한 통제 설계다. 5시드, 중앙값 + IQR 보고.

**평가:** 2~9cm 장애물, 1000 롤아웃, 성공률 SR = 1 − 조기종료율, 외란 7.5~30N 무작위 인가.

**실기:** Unitree Go2 + L1 LiDAR + Point-LIO → 셀별 (평균 높이, 분산) elevation grid map(Fankhauser 2018) + median-fill(작은 구멍만 인페인트) → 로봇 중심 11×9 그리드(1.1×0.9m) 하이트맵. 정책 50Hz, PD $$k_p = 60, k_d = 3$$. ANYmal-C는 하이퍼파라미터 무변경 예비 실험.

| 항목 | 수치 |
|---|---|
| 이산 장애물 SR (중앙값, 25%, 75%) | PGTT 0.848 / 0.842 / 0.855 · Wild 0.756 / 0.756 / 0.769 · MassLoco 0.702 / 0.659 / 0.711 |
| 외란 SR | PGTT 최고, 차선(Wild) 대비 중앙값 +7.5% |
| 속도 추종 $$\bar{v} / \bar{\omega}$$ | PGTT 0.965 / 0.991, 세 방법 유사 |
| 수렴 | PGTT ≈ Wild, MassLoco는 레벨 1에서 약 2배 느림 |
| Ablation (7cm 계단) | full 0.834 / w/o foot phase 0.755 / w/o foot contact 0.826 |
| 실기 | Go2 정성 성공(영상), 최대 0.4m/s. ANYmal-C 예비: 하이퍼파라미터 무변경으로 보행 생성 |

핵심 결과 세 가지로 정리된다.

1. **이산 장애물 SR 0.848**로 Wild 0.756, MassLoco 0.702 대비 차선보다 9%p 높고, 속도 추종은 세 방법이 동등하다. 성공률 향상이 추종을 희생하지 않고 달성됐다.
2. **Ablation이 메커니즘을 입증한다.** foot phase 항을 빼면 SR 0.834에서 0.755로 떨어져 이 항이 주 동력임을 보이고, foot contact 항은 0.826에서 0.834로 엣지 케이스를 보강한다. PGTT의 근소한 속도 추종 저하는 계단에서 속도보다 균형을 우선하는 행동의 반영이다.
3. **Go2 실기 sim-to-real 성공.** 계단과 이산 장애물을 보행하고 실제 외란을 버텼다. L1 LiDAR의 희소성(21,600 points/s)으로 최대 0.4m/s로 제한됐다.

주장 대 실제를 따져 보면 두 가지 주의점이 있다. 첫째, 비교된 "Wild"는 원논문의 teacher-student·belief encoder 전체 시스템이 아니라 보상 항만 이식한 재구현이다. 통제 실험으로는 올바르지만 "Wild 시스템을 이겼다"로 읽으면 과대해석이다. 둘째, "형태 무관(morphology-agnostic)" 주장의 근거는 ANYmal-C에서 하이퍼파라미터 무변경으로 보행이 생성된다는 정성·예비 결과뿐이며 성공률은 없다. 저자도 preliminary로 명시했다.

## 결론과 의의

이 논문은 "구조를 어디에 넣는가"의 답을 바꿨다. gait prior의 자리를 action space(오실레이터/IK)에서 reward로 옮겨도 성능이 유지·향상됨을 통제 실험으로 보였고, 이후 인지형 보행 RL에서 "IK 없는 위상 prior"가 정당한 기본 선택지가 된다. $$\delta H$$ 라는 스칼라 하나로 스윙 정점을 조절하는 최소 장치가 이산 장애물 SR을 9%p 끌어올린 것은, 복잡한 지형 인코더 없이도 인지에서 보행으로의 연결이 가능함을 보여준 사례다. MJX + BRAX 스택으로 학습 비용을 소비자 GPU 한 장, 세 시간대로 낮춘 것도 커뮤니티 관점의 실질 기여다.

로봇 실무 관점에서 정리하면 다음과 같다.

- **쓸 수 있는 곳:** 사족보행 시뮬레이션 테스트베드에서 계단·이산 장애물 보행 정책을 직접 학습·교체하고 싶을 때. 리포지토리에 학습(PGTT/baseline/wild 3변형, 커리큘럼), 시뮬 배포, 실기 배포(Unitree SDK, 조이스틱, Docker + ROS 2 인지 파이프라인), WFC 지형 생성, 평가 유틸이 완결되어 있다. 재현 난이도는 하~중이며, 막힐 곳은 JAX/CUDA 버전 정합과 실기 Point-LIO Docker 구성 정도다. 사전학습 체크포인트 제공 여부는 문서상 확인되지 않았다.
- **인지 스택의 표준화:** 실기 파이프라인이 Point-LIO + 확률적 elevation map + median-fill + 로봇 중심 하이트맵이라는 범용 부품으로 구성되어, 실내 다층 건물 모바일 로봇 자율주행용 elevation mapping 스택을 이미 갖춘 팀이라면 인지 입력을 자급할 수 있다.
- **학습 분포의 한계:** 커리큘럼 최대 단차 13cm, 5×5 타일 국소 장면 중심이라 장거리 연속 계단(스위치백)이나 자갈·경사가 섞인 비정형 연속 지형, 미끄러운 노면은 미검증이다. 정지·저속 거동도 학습하지 않으므로(MassLoco의 stand still 항 없음) 운용 계층에서 정지 게이트를 보완해야 한다.
- **실기 속도와 센서:** L1 LiDAR 희소성으로 0.4m/s 상한이 걸렸는데, 하이트맵 갱신 지연 대 속도의 정량 관계는 제시되지 않았다. 더 조밀한 LiDAR로 완화될 것으로 기대되지만 검증은 없다.
- **미평가 항목:** 에너지 효율(저자 인정), median-fill 보정의 실패 모드(큰 구멍, 동적 물체)와 정책 강건성의 경계. 다형태 단일 정책(보상의 형태 조건화)은 future work다.
