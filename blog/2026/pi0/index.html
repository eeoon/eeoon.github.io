π0: A Vision-Language-Action Flow Model for General Robot Control (arXiv 2024)

Created on June 11, 2026

항목 내용
저자 Kevin Black, Noah Brown, Danny Driess, Michael Equi, Chelsea Finn, Karol Hausman, Brian Ichter, Liyiming Ke, Sergey Levine, Suraj Nair, Karl Pertsch, Lucy Xiaoyang Shi, Quan Vuong 외 (Physical Intelligence, San Francisco)
발표 arXiv 2410.24164, 2024-10-31 프리프린트 (별도 학회 게재는 확인되지 않음, 회사 블로그와 동시 공개)
링크 arXiv · Blog · Code (openpi, Apache-2.0)

한 줄 요약

π0(파이-제로)는 사전학습된 VLM(PaliGemma 3B) 위에 flow matching으로 연속 행동을 생성하는 별도의 action expert(약 0.3B)를 붙인 로봇 파운데이션 모델이다. 7종 로봇 구성·68개 과제·약 1만 시간의 크로스 임바디먼트 데이터로 사전학습한 뒤 과제별 고품질 데이터로 포스트학습하면, 빨래 개기·식탁 정리·상자 조립 같은 수십 분짜리 장기 정교(dexterous) 조작을 50Hz로 수행한다. Physical Intelligence의 첫 대표 모델이며, 이후 π0.5·π*0.6으로 이어지는 계보의 출발점이다.

연구 계보와 동향

π0가 나온 배경은 네 갈래의 흐름이 합쳐지는 지점으로 정리할 수 있다.

  1. 자기회귀 토큰 방식의 VLA. RT-2와 OpenVLA는 사전학습 VLM을 로봇 데모로 파인튜닝하되, 행동을 텍스트 토큰처럼 이산화해 출력했다. 인터넷 지식을 로봇으로 옮긴 핵심 흐름이지만, 이산 토큰을 자기회귀로 디코딩하므로 action chunking을 지원하지 못하고 디코딩이 느려 고주파·정교 조작에 약하다.
  2. 확산 기반 행동 생성. Diffusion Policy와 Octo는 행동을 확산 모델로 생성해 멀티모달·연속 분포를 잘 표현한다. 다만 대부분 VLM 백본이 없어 인터넷 스케일 의미 지식을 가져오지 못한다.
  3. Action chunking. ACT(ALOHA)는 한 번에 H스텝의 행동 묶음을 예측해 양손 정교 조작을 가능하게 했지만, 수십~수백 데모 규모의 단일 과제에 한정됐다.
  4. 토큰별 손실 혼합. Transfusion은 한 트랜스포머 안에서 next-token 예측과 diffusion을 함께 학습했고, Playground v3는 확산 토큰에 별도 가중치를 두었다. π0는 이 아이디어를 VLA로 가져와 “이미지·텍스트는 cross-entropy, 행동은 flow matching”을 하나의 트랜스포머에서 처리한다.

π0는 위 네 갈래를 통합한다. VLM 사전학습, flow matching, action chunking, 크로스 임바디먼트, 그리고 LLM식 pre/post-training 레시피를 한데 묶었고, 저자들은 “고주파 행동 청크를 내는 최초의 flow matching VLA”라고 주장한다.

후속 계보는 다음과 같다. π0-FAST는 자기회귀 토큰화를 개선한 FAST tokenizer 버전이다. π0.5는 오픈월드 일반화를 강화하고 Knowledge Insulation(stop-gradient로 action expert가 백본 표현을 망치지 않게 하는 학습법)을 도입했다. π*0.6(2025-11)은 RECAP이라는 오프라인 RL 레시피로 모델이 자기 성공·실패에서 학습하도록 확장했다. 즉 π0 라인은 모방학습에서 경험 기반 RL로 이동하는 중이다.

문제와 동기

로봇 학습의 3대 병목은 데이터 부족·일반화·견고성이다. π0는 이를 LLM/VLM의 성공 공식, 즉 “다양한 대규모 데이터로 사전학습한 뒤 좁고 고품질인 데이터로 정렬”하는 방식으로 풀자고 제안한다. 다만 이를 로봇에 옮기려면 세 가지가 동시에 필요하다.

  • 규모. 작은 규모에서는 사전학습 이득이 나타나지 않는다.
  • 아키텍처. 다양한 데이터를 흡수하면서도 정교하고 미묘한 물리 행동을 표현할 수 있어야 한다.
  • 학습 레시피. 저자들은 이것이 가장 중요하다고 강조한다.

직관적인 비유로, 고품질 데이터만 학습한 모델은 실수에서 회복하는 법을 배우지 못해 부서지기 쉽고(brittle), 저품질 사전학습 데이터만 학습한 모델은 유려하고 효율적으로 행동하지 못한다. 둘을 합치면 “최대한 고품질처럼 행동하되, 실수 시 복구 레퍼토리를 갖춘” 모델이 된다.

핵심 아이디어와 방법

VLM 백본: 인터넷 지식의 수입구

PaliGemma 3B(SigLIP 이미지 인코더 + Gemma 2B 언어모델)를 백본으로 초기화한다. 이미지와 언어를 late fusion으로 같은 임베딩 공간에 넣어 의미 추론·언어 이해 능력을 그대로 상속한다. 비유하자면 “이미 세상을 읽을 줄 아는 뇌”에 손발만 달아주는 셈이다. 논문은 PaliGemma를 편의성과 작은 크기(실시간 제어에 유리) 때문에 골랐을 뿐, 프레임워크 자체는 어떤 사전학습 VLM과도 호환된다고 밝힌다.

Action expert: 연속 행동 출력 모듈

VLM에는 없던 입력(고유감각 상태 \(q_t\))과 출력(행동 청크 \(A_t\))을 처리하는 별도 가중치 세트(약 0.3B)다. 핵심 트릭은 하나의 트랜스포머를 두 개의 expert(MoE 2개)로 보는 것이다. 이미지·텍스트 토큰은 큰 VLM expert로, 상태·행동 토큰은 작은 action expert로 라우팅하고, 두 expert는 self-attention 층에서만 상호작용한다. action expert는 width 1024, MLP 4096으로 축소해(백본 Gemma 2B는 width 2048, MLP 16384) flow 적분 시 여러 번 forward해도 추론 속도를 확보한다.

Flow matching: 행동 분포를 그리는 법

action expert는 조건부 flow matching으로 연속 행동 청크 \(A_t = [a_t, \ldots, a_{t+H-1}]\) (\(H = 50\))를 생성한다. 학습 목표는 다음과 같다.

\[L^\tau(\theta) = \mathbb{E}_{p(A_t|o_t),\, q(A_t^\tau|A_t)} \left\| v_\theta(A_t^\tau, o_t) - u(A_t^\tau | A_t) \right\|^2\]
확률 경로는 단순한 linear-Gaussian(OT) 경로 $$q(A^\tau A) = \mathcal{N}(\tau A, (1-\tau) I)\(를 쓴다. 노이즈\)\epsilon \sim \mathcal{N}(0, I)\(로부터\)A^\tau = \tau A + (1-\tau)\epsilon\(을 만들고, 네트워크 출력\)v_\theta\(가 벡터장\)u = A - \epsilon\(을 맞추도록 학습한다. 추론 시에는\)\tau = 0\((순수 노이즈)에서\)\tau = 1$$(행동)까지 forward Euler로 적분한다.
\[A^{\tau + \delta} = A^\tau + \delta \, v_\theta(A^\tau, o_t), \quad \delta = 0.1\]

즉 10스텝이면 충분하다. 확산과 형제 관계지만 직선 경로라 적은 스텝으로 수렴하고, 정교·멀티모달·고정밀 행동 표현에 적합해 50Hz 제어가 가능하다. 이산 토큰의 cross-entropy 대신 행동 토큰에만 flow matching 손실을 적용한다.

Blockwise causal attention과 KV 캐싱

어텐션 마스크를 세 블록으로 나눈다. [이미지+언어] / [상태 \(q\)] / [노이즈 행동 \(A^\tau\)]. 각 블록 내부는 양방향이고 미래 블록은 보지 못한다. 효과는 두 가지다. 첫째, 관측(prefix)의 key/value를 한 번만 계산해 캐싱하고, 10번 반복하는 flow 적분에서는 행동 토큰만 다시 계산하므로 추론이 효율적이다. 둘째, VLM 사전학습 때의 입력이 새로 추가된 입력을 보지 못하게 막아 분포 시프트를 최소화한다.

타임스텝 샘플링 설계

학습 시 flow timestep \(\tau\)를 균등이 아니라 저timestep(고노이즈) 구간을 강조하는 beta 분포에서 샘플한다.

\[p(\tau) = \mathrm{Beta}\left(\frac{s - \tau}{s};\, 1.5,\, 1\right), \quad s = 0.999\]
이미지 합성과 달리 로봇에서는 관측이 행동을 강하게 제약하므로 “평균 행동 예측” $$\mathbb{E}[A o]$$이 더 어렵다는 가설에서 나온 설계다. 노이즈가 큰 구간을 더 많이 학습시킨다.

Pre/post-training 레시피

단계 데이터 목적
사전학습 OXE + Bridge v2 + DROID(전체의 9.1%) + 자체 903M 스텝(단팔 106M, 양팔 797M, 68과제) 폭넓은 물리 능력·복구 행동 습득
포스트학습 과제별 5~100시간 이상의 고품질 정선 데이터 유려하고 일관된 전략 정렬

사전학습 믹스는 task-robot 조합별 표본 수 \(n\)에 대해 \(n^{0.43}\)으로 가중해 과대표된 조합을 down-weight한다. 상태·행동 벡터는 가장 큰 로봇 차원(18차원: 두 6-DoF 팔, 두 그리퍼, 모바일 베이스, 수직 토르소)에 맞춰 zero-pad하고 부족한 이미지 슬롯은 마스킹한다. 언어 라벨은 과제명과 약 2초 길이의 세그먼트 주석을 함께 쓴다.

식탁 정리(bussing)처럼 의미 추론이 필요한 과제는 고수준 VLM 정책이 SayCan 방식으로 “냅킨을 집어라”, “쓰레기통에 버려라” 같은 중간 언어 명령을 내려 분해하고, π0가 이를 실행한다.

실험과 결과

시스템 구성. PaliGemma 3B + action expert 0.3B로 총 3.3B다. VLM 사전학습 효과를 분리하기 위해 비-VLM baseline π0-small(470M, DistilBERT + ViT + DiT)도 함께 학습했다. 자체 데이터는 UR5e, Bimanual UR5e, Franka, Bimanual Trossen(ALOHA), Bimanual ARX·AgileX, Mobile Trossen·ARX, Mobile Fibocom의 7종 구성이다. 본 모델은 700k 스텝을 학습했고, baseline과의 compute parity를 위해 160k 스텝 버전도 평가했다.

추론 비용(RTX 4090). 이미지 인코딩 14ms + 관측 forward 32ms + flow 10스텝 27ms로 온보드 73ms(오프보드 86ms)다. 행동 청크는 open-loop로 실행하며, temporal ensembling은 오히려 성능을 떨어뜨려 폐기했다. 20Hz 로봇은 0.8초마다(16행동), 50Hz 로봇은 0.5초마다(25행동) 재추론한다.

평가군. ① 포스트학습 없이 직접 프롬프트(셔츠 개기, bussing easy/hard, grocery bagging, toast) ② 언어 명령 추종(flat / 사람 중간명령 / 고수준 VLM) ③ 신규 정교 과제 파인튜닝(데이터 1/5/10시간) ④ 초복잡 다단계 과제(빨래 개기, box building, packing eggs 등). 비교군은 OpenVLA(7B), Octo(93M), ACT, Diffusion Policy다.

핵심 결과 세 가지는 다음과 같다.

1. Out-of-box에서 압도. π0(700k)가 전 과제에서 최고였고 셔츠 개기·쉬운 bussing은 거의 만점이었다. 160k parity 버전조차 모든 baseline을 능가했으며, VLM 없는 π0-small도 OpenVLA·Octo를 이겼다. OpenVLA는 action chunk를 지원하지 않아 고주파 정교 과제에서 무너졌다.

2. VLM 사전학습이 언어 추종을 끌어올린다. 언어 명령 추종에서 π0가 π0-small을 크게 앞섰고, 사람 중간명령(π0-human)과 고수준 VLM(π0-HL) 가이드 모두에서 이득을 봤다. π0-small은 언어 능력이 제한적이라 고수준 가이드의 이득이 없었다.

3. 초장기 정교 과제 달성. 빨래 개기(임의로 구겨진 상태에서 꺼내·펴·개기), 모바일 빨래, dryer 비우기, 미본 객체의 식탁 bussing, box building, packing eggs, to-go box 등 5~20분짜리 과제에서 풀 레시피(사전학습 + 파인튜닝)가 전 과제에서 최대점의 50% 이상을 달성했다. 저자들은 이를 end-to-end 로봇 학습 문헌상 가장 긴 정교 과제라고 본다.

파인튜닝 상세. 신규 과제 파인튜닝에서 π0가 ACT·Diffusion Policy·OpenVLA·Octo 대비 대체로 우위였다. 흥미로운 점은 기존 모델들은 scratch 학습이 사전학습보다 나았다는 것으로, 기존 방식은 사전학습 전이가 어렵다는 방증이다. π0는 사전학습이 scratch 대비 최대 2배 개선을 보였고, 데이터가 적을수록·과제가 어려울수록 사전학습 이득이 컸다.

주장 대 실제. “최초의 flow matching VLA”라는 주장은 통합적 기여로서 신규성이 인정되지만, 개별 컴포넌트는 선행연구 기반임을 저자들도 명시한다. “역대 최대 사전학습 믹스”는 규모 자체는 사실로 보이나 자체 데이터가 비공개라 외부 검증이 불가능하다. “새 SOTA 정교 조작”은 실로봇 데모가 강력하지만 이 난도의 과제를 돌릴 수 있는 기존 모델이 거의 없어 일부는 ablation 비교에 그쳤고, 과제당 10 trial로 표본이 적다.

결론과 의의

π0는 VLA를 “이산 토큰 자기회귀”에서 “VLM + 연속 flow matching action expert”로 옮긴 분기점이다. 이후 거의 모든 정교 조작 VLA가 action expert + flow/diffusion + action chunking이라는 청사진을 따르게 됐다. 더 중요한 메시지는 아키텍처보다 레시피다. LLM식 pre/post-training이 로봇에도 통하며, 사전학습이 일반성과 회복력을, 포스트학습이 유려함을 준다는 경험적 증거를 제시했다. openpi 공개로 재현·확장의 표준 출발점이 됐다.

로봇 실무 관점에서의 활용 가능성과 한계는 다음과 같다.

  • 공개 base 체크포인트 파인튜닝이 현실적 경로다. openpi(Apache-2.0, JAX + 2025-09 PyTorch 지원)에 π0·π0-FAST·π0.5 base와 ALOHA/DROID/LIBERO 파인튜닝 체크포인트가 공개돼 있다. 추론은 8GB 이상(RTX 4090급), LoRA 파인튜닝은 22.5GB 이상, full 파인튜닝은 70GB 이상(A100/H100)이 필요하다. 추론 73ms는 4090 한 장으로 가볍다.
  • 처음부터 사전학습을 재현하는 것은 사실상 불가능하다. 자체 1만 시간 데이터가 비공개이고, 7종 실로봇과 대규모 GPU가 필요하다. 재현 난이도는 파인튜닝·추론 기준 중, 논문 전체 기준 상이다.
  • 사전학습 믹스 구성 원리가 없다. 어떤 데이터를 얼마나 섞어야 좋은지 설명이 없고(저자 인정), 어느 정도 데이터가 있어야 near-perfect에 도달하는지 예측할 수 없다. 일부 과제는 신뢰성이 미달이다.
  • 다른 도메인으로의 전이는 미확인이다. 자율주행·내비게이션·다리 로코모션처럼 매우 다른 도메인까지 양성 전이가 보편적인지는 검증되지 않았다. 실내 다층 건물 모바일 로봇 자율주행이나 사족보행 시뮬레이션 테스트베드에 적용하려면 별도 검증이 필요하다.
  • Open-loop 청크 실행의 반응성 문제. temporal ensembling이 성능을 해쳐 폐기했으므로, 장기적으로 반응성 저하와 오류 누적 우려가 남는다.
